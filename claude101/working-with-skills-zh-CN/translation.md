# Claude 101

## 使用技能 (Working with Skills)

预计时长：15 分钟

### 学习目标

完成本课后，你将能够：

- 解释什么是技能（Skills）以及 Claude 如何使用它们
- 识别 Anthropic 内置于文档创建的内置技能
- 在设置中启用和管理技能

### 什么是技能？

技能是包含指令、脚本和资源的文件夹，Claude 会动态加载它们，以提升在特定任务上的表现。可以将它们理解为专业能力包——它们教会 Claude 如何以可重复的方式完成特定任务。

如果你曾使用 Claude 创建 Excel 电子表格、PowerPoint 演示文稿、Word 文档或 PDF，你其实已经见证了技能的实际运作。这些文件创建能力背后正是技能在默默驱动。但技能远不止于文档创建。自定义技能（Custom Skills）可以将整个可复用的工作流固化为标准流程——季度差异分析方法论、品牌声音审核流程或合规检查清单——让 Claude 每次都遵循同样严格的步骤。

### 技能的类型

你会遇到两类技能：

- Anthropic 官方技能（Anthropic Skills）由 Anthropic 创建和维护。这些包括针对 Excel、Word、PowerPoint 和 PDF 文件的增强文档创建能力。Anthropic 技能面向所有付费用户开放，Claude 会在相关场景中自动调用它们——你无需做任何特殊操作即可使用。
- 自定义技能（Custom Skills）是你或你的组织为特定工作流和领域专属任务而创建的。例如，你可能会创建一个技能，将公司的品牌指南应用于演示文稿、按特定格式整理会议记录，或执行组织内的数据分析工作流。

### 启用技能

技能目前作为功能预览面向 Pro、Max、Team 和 Enterprise 套餐用户开放。要使用技能，你需要先启用代码执行（Code Execution）和文件创建功能，因为技能需要 Claude 的安全沙箱式计算环境才能运行。

以下是启用技能的方法：

1. 前往「设置」>「能力」（Capabilities）
2. 确保「代码执行和文件创建」已切换为开启
3. 滚动到「技能」区域
4. 根据需要单独开启或关闭各项技能

对于 Enterprise 套餐，组织所有者必须先在管理员设置中同时启用「代码执行」和「技能」，然后组织成员才能访问。

对于 Team 套餐，此功能预览在组织级别默认启用。

启用后，你将在设置中看到可用的技能列表，包括 Anthropic 的内置技能以及你上传的任何自定义技能。

### 在实践中使用技能

技能的便捷之处在于你通常无需刻意考虑它们——Claude 会根据你的请求自动选择合适的技能。以下是一些会触发技能调用的提示词示例：

- 「创建一份跟踪月度开支的 Excel 电子表格，并加入合计公式」
- 「把这份会议记录文档转换为 PowerPoint 演示文稿」
- 「生成一份汇总这些数据的 PDF 报告」
- 「在 Excel 中构建一个包含情景分析的财务模型」

当 Claude 使用技能时，你会在 Claude 的思维链中看到相关提示。最终输出将是一个可下载的文件，你可以保存到电脑或直接保存到 Google Drive。

#### 安全注意事项

由于技能可能包含可执行代码，使用时需要谨慎：

- 仅安装来自可信来源的自定义技能
- Anthropic 的内置技能经过 Anthropic 测试和维护

- 如果你要安装来自外部来源的自定义技能，先审阅其内容以了解其功能

### 创建自定义技能

虽然 Anthropic 的内置技能覆盖了常见的文档创建任务，但技能真正的力量来自创建你自己的技能。自定义技能让你可以教会 Claude 你独有的工作流程、品牌指南和工作方式——这样 Claude 就能在相关场景中自动应用这些知识。

创建自定义技能最简单的方法就是通过与 Claude 对话来实现。你不需要编写代码或手动创建文件——Claude 会为你处理技术结构。

以下是通过对话创建技能的方法：

1. 开启一场新对话，告诉 Claude 你想创建什么。例如：「我想创建一个用于撰写季度业务评审的技能」或「我需要一个能将我们品牌指南应用于演示文稿的技能」。
2. 回答 Claude 的问题。Claude 会就你的工作流程采访你，询问诸如：这个技能应该做什么？这类工作怎样的输出才算优秀？你能举例说明会在什么情况下使用这个技能吗？
3. 上传参考资料（如有）。模板、风格指南、品牌素材或你引以为傲的工作成果示例，都能帮助 Claude 精准理解你的需求。
4. 保存你的技能。完成后，Claude 会生成一个包含结构正确的技能文件。你只需保存它，技能即可为 Claude 所用。

查看你的技能。在左侧边栏中找到「自定义」（Customize）标签。在这里，你可以查看你拥有的所有技能，甚至可以手动或通过与 Claude 对话来编辑你正在使用的技能。

你的自定义技能将与 Anthropic 内置技能一并出现在技能列表中。从那时起，每当你在相关任务中工作时，Claude 都会自动调用它——无需手动触发。你可以通过持续迭代来完善你的技能——让 Claude 编辑某个技能，它就会自动帮你更新相关文件。

### 技能 vs. 项目

你可能会想——如果技能和项目都可以为 Claude 提供更多上下文，我应该在什么时候用哪一个？可以这样理解：项目存储的是知识，技能执行的是任务。

项目是知识中心。它们保存 Claude 理解你的工作所需的参考资料——项目规格说明、会议记录、研究文档。当你在一个项目中上传文件后，Claude 会该项目内的每次对话中引用这些信息。

技能是流程机器。它们编码了 Claude 应如何执行某项任务——你每次希望遵循的具体步骤、操作顺序和方法论。当你有希望 Claude 始终一致执行的可复用工作流时，技能就是最佳选择。

两者是互补的。一个技能可以引用存储在某个项目中的知识——你的「客户电话准备」技能可能会从上传到项目知识库中的客户档案中提取信息。项目提供「什么」（信息），技能提供「如何」（流程）。

|  | 项目 (Projects) | 技能 (Skills) |
| --- | --- | --- |
| 用途 | 存储 Claude 参考的知识 | 定义 Claude 执行的流程 |
| 最适合 | 长期上下文、参考资料、团队协作 | 可复用工作流、多步骤任务、一致的方法论 |
| 示例 | 客户中心、研究助手、反馈生成器 | 流程指南（如品牌或法务）、博客撰写、PDF 创建 |
| 持久性 | 知识在项目中所有对话均可访问 | 指令在技能被调用时应用 |
