# Claude 101

## 企业搜索 (Enterprise Search)

预计时长：15 分钟

### 学习目标

完成本课后，你将能够：

- 解释什么是企业搜索（Enterprise Search）以及它能回答哪些类型的问题
- 了解管理员和普通用户各自如何完成设置流程
- 理解安全与权限机制如何保护组织数据

### 什么是企业搜索？

企业搜索会在你的侧边栏中添加一个专用的「向{您的组织名称}提问」选项。它专为查找和综合散布于公司各种工具和数据源中的知识而设计。可将企业搜索理解为面向你整个组织的预配置项目（Project）——公司的知识库已经加载完毕，你可以随时开始提问，获得结合上下文的精准回答。

与启用了连接器（Connectors）的常规对话不同，企业搜索专门针对信息收集场景进行了优化，使用了由 Anthropic 团队配置的自定义指令。

### 你可以问什么？

企业搜索尤其适合那些需要跨越多个信息源、综合组织各处信息的问题。以下是一些常见使用场景：

快速了解最新动态

- 「昨天我不在的时候发生了什么？」
- 「总结上周业务层面的关键更新」
- 「Platform 项目目前有哪些阻塞项？」

制度和流程问题

- 「公司的远程办公政策是什么？」
- 「如何提交报销报告？」
- 「请假的流程是怎样的？」

调研与分析

- 「客户选择竞品的主要原因有哪些？」
- 「总结关于 Q4 产品路线图的讨论」
- 「查找关于客户入职流程的相关信息」

新成员入职

- 「我们的认证系统是如何运作的？」
- 「想了解计费系统，我应该找谁？」
- 「工程团队使用哪些工具进行部署？」

绩效与项目跟踪

- 「查找与营销活动相关的讨论和文档」
- 「上周领导层会议的关键决策有哪些？」
- 「总结各团队对 Infrastructure 计划的贡献」

当你提出问题时，Claude 会搜索所有已连接的工具——例如 SharePoint 文档、Slack 对话、Gmail 邮件线程和 Google Drive 文件——并将信息综合为一份统一的回答。此外，它始终会注明信息来源，方便你获取完整上下文。

### 设置企业搜索

企业搜索需要两步设置：首先由管理员为组织完成配置，然后每位用户使用自己的个人账号进行身份认证。

#### 面向管理员（所有者）

企业搜索项目默认对所有团队（Team）和企业（Enterprise）级组织启用，但需要所有者（Owner）完成初始设置后，团队成员才能使用：

1. 点击左侧边栏中的「向您的组织提问」。
2. 点击「为您的组织设置」继续（或点击「禁用」关闭该功能）。
3. 连接你所在组织的工具。你需要为文档选择连接器（如 Google Drive 或 SharePoint），并为聊天选择连接器（如 Slack 或 Microsoft Teams）。邮箱推荐连接但非必选。
4. 点击「+ 添加更多」来设置团队所需的其他工具。
5. 自定义项目名称。你输入的内容将以「向[名称]提问」的形式出现在每个人的侧边栏中。
6. 添加一段描述，然后点击「完成设置」。

设置完成后，该项目将对组织中的所有成员开放。

#### 面向用户

管理员设置好企业搜索后，你会在侧边栏中看到「向{组织名称}提问」项目已被星标收藏。以下是入门步骤：

1. 点击侧边栏中的该项目。
2. 按照引导式入门流程连接到推荐的服务。
3. 对每一个你想搜索的服务进行身份认证（Slack、Google、Microsoft 365 等）。
4. 开始向 Claude 提问关于组织知识库的问题。

你启用的连接器越多，搜索结果就越全面。你随时可以在项目的「指令」区域点击「连接」来添加更多连接器。

### 这么多数据……安全吗？

简而言之：安全。企业搜索只会显示你在原始连接工具中已有权访问的内容。此外，你的对话保持私密，已连接的数据不会被单独索引或存储。

### 课程反思

继续之前，请思考：

- 你平时经常向同事请教的哪些问题，其实可以通过搜索组织文档和沟通记录获得答案？
- 在入职或培训场景中，企业搜索能如何帮助新成员更快上手？
- 针对你的具体岗位，连接哪些数据源最有价值？
