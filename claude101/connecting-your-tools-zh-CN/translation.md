# Claude 101

## 连接你的工具 (Connecting Your Tools)

预计时长：20 分钟

### 学习目标

完成本课后，你将能够：

- 解释什么是连接器（Connectors）以及它们对你使用 Claude 的意义
- 浏览连接器目录并设置你的首个连接
- 在与 Claude 的对话中有效使用已连接的工具

### 什么是连接器？

#### 核心要点

- 连接器将 Claude 从一个助手转变为一个了解情况的合作伙伴，让 Claude 能够访问你日常使用的工具、数据和上下文。无需每场对话都从零开始，Claude 可以直接处理你的真实信息。
- 连接器允许 Claude 读取信息并代替你执行操作。根据连接器和所授予的权限，Claude 可以搜索你的文件、检索文档、分析数据、创建新内容、更新记录，以及在你已连接的应用中执行任务——所有这些都从你的对话中发起。
- 模型上下文协议（MCP，Model Context Protocol）是驱动连接器的底层标准。可将 MCP 理解为 AI 世界的 USB-C——一种通用标准，使 Claude 能够通过统一、一致的接口连接到众多不同的应用。这一开放标准意味着开发者可以为任何工具构建连接器，并且这些连接器可以与 Claude 无缝协作。
- 连接器分为两类：Web 连接器和桌面扩展（Desktop Extensions）。Web 连接器将 Claude 连接到云服务，如 Google Drive、Notion、Slack 和 Asana。桌面扩展通过 Claude 桌面应用在本地计算机上运行，让 Claude 可以访问本地文件和原生应用。

### 查找和连接工具

Anthropic 在 `claude.ai/directory` 维护着一个推荐连接器目录。该目录包含两个标签页：

- Web：云服务和应用（Gmail、Notion、Slack、Asana、Linear、Stripe 等）
- 桌面扩展：通过 Claude 桌面应用在计算机上运行的本地工具

要浏览可用的连接器，你也可以点击聊天窗口左下方的 `+` 按钮，然后选择「连接器」（Connectors）。

#### 设置 Web 连接器

连接云服务的步骤如下：

1. 找到连接器：访问 `claude.ai/directory`，或在任何对话中点击 `+` >「连接器」
2. 点击「连接」（Connect）：选择你要添加的连接器
3. 身份认证：你将被重定向至该服务的登录页面，使用现有凭据登录
4. 授予权限：查看 Claude 请求的具体权限，然后授权访问
5. 测试连接：返回 Claude 并尝试一个简单请求，如「你能访问我的[工具名称]吗？」

连接成功后，Claude 可以在该服务中进行搜索、读取，在某些情况下还可以执行操作——这取决于你授予的权限。

#### 桌面扩展

桌面扩展需要使用 Claude 桌面应用，而非网页端界面。这些扩展允许 Claude 与本地应用、你的文件系统以及 macOS 或 Windows 的原生功能进行交互。

一些桌面扩展包括：

- 本地文件访问：读取和整理文档
- 浏览器控制：自动执行网页任务
- 原生应用集成（如用于设计工作的 Figma）

安装桌面扩展的步骤：

1. 下载并安装 Claude 桌面应用
2. 打开应用，前往「设置」>「扩展」（Extensions）
3. 浏览可用扩展并点击「安装」（Install）
4. 按照该扩展的具体设置步骤完成后续操作

### 在工作流中使用连接器

连接工具后，Claude 在回复你的请求时会综合考虑这些工具的信息。以下是一些使用已连接工具的实用方式：

项目管理（Asana、Linear、Jira）

- 「我本周有哪些最高优先级的任务？」
- 「创建一个新任务，用于评审 Q4 预算提案」
- 「总结我们产品发布项目的当前状态」

沟通协作（Slack、Gmail）

- 「找到我们讨论供应商合同的那封邮件线程」
- 「为 #营销 频道中的最新消息草拟一条回复」
- 「团队在昨天的讨论中对时间线做出了什么决定？」

文档（Notion、Google Drive、Confluence）

- 「搜索我们的文档，查找品牌声音指南」
- 「总结上周产品评审会议记录」
- 「我们的风格指南中对缩写使用是怎么规定的？」

商业工具（Stripe、PayPal、Salesforce）

- 「展示过去一个季度的收入趋势」
- 「Acme Corp 商机目前是什么状态？」
- 「列出近期超过 $1,000 的交易」

### 安全与权限

当你将 Claude 连接到外部服务时，你授予了它读取——有时也包括修改——这些服务中数据的能力。以下是一些重要注意事项：

- 限定范围的访问：权限精确限定为连接器所需的内容，你可以在每个应用的菜单中单独开关各个权限。
- Claude 只能看到你能看到的内容：Claude 只能访问你有权限访问的数据。连接你的工作邮箱并不会让 Claude 访问你 CEO 的收件箱——只有你自己的。
- 随时可撤销：你可以通过 Claude 的设置或第三方服务的安全设置断开某个服务的连接。与技能（Skills）一样，你也可以查找或构建自定义连接器。同样需要谨慎——仅安装来自可信来源的连接器。

### 课程反思

继续之前，请思考：

- 你日常使用的工具中，哪些最值得连接到 Claude？
- 哪些任务目前需要你手动复制粘贴信息，而连接器可以自动处理这些？
- 是否有某些工作流，如果能结合来自多个已连接数据源的信息，可以为你节省大量时间？
