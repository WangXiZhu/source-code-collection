### 什么是 Claude？

（10 分钟）

Claude 不仅仅是一个聊天机器人——它是一个被设计为你思考伙伴（Thinking Partner）的 AI 助手。在本课中，你将了解 Claude 与其他 AI 工具有何不同，并看到它如何帮助处理各种工作任务。

#### 核心要点

- Claude 以有用（Helpful）、无害（Harmless）和诚实（Honest）为构建原则：在宏观层面，Claude 遵循一系列原则，避免产生有毒或歧视性输出，避免协助人类从事非法或不道德的活动，并在整体上表现为一个有用、诚实且无害的 AI 系统。这种方法被称为宪法式 AI（Constitutional AI），意味着 Claude 经过训练以符合人类价值观并保持透明运作。
- Claude 不仅仅是聊天机器人：Claude 能够处理各种对话和文本处理任务，同时保持高度的可靠性和可预测性，包括摘要总结、搜索、创意与协作写作、问答、编程等。将 Claude 视为一个思考伙伴，它可以帮助你应对复杂问题、处理棘手情况，而不仅仅是回答简单问题。
- Claude 被设计为可引导和可协作的：Claude 可以接受关于个性、语气和行为的引导，用户反馈表明，Claude 更不容易产生有害输出、更容易对话且更可引导——让你可以用更少的精力获得期望的输出结果。
- 你可以在任何工作场景中访问 Claude：Claude 应用适用于所有套餐类型——Free（免费版）、Pro、Max、Team 和 Enterprise（企业版）。登录后，你的对话、项目、记忆和偏好设置会在所有设备之间同步。无论你是在办公桌前还是在路上，都可以通过网页端、桌面端和移动端应用访问 Claude。

### 理解 Claude 的能力

Claude 能够帮助你完成的任务范围远超简单的问答互动，它能提供类似助手般的伙伴关系，既能自动化也能增强你的工作。以下是 Claude 擅长的一些方面：

- 写作与内容创作：Claude 可以与你协作撰写社交媒体帖子、专业邮件和复杂报告。由于 Claude 经过训练可以接受关于个性和语气的引导，你们可以一起迭代优化结构和表述，直到你的语言风格清晰地传达出来。
- 研究与分析：Claude 帮助你探索研究角度、汇编发现成果，并分析数据以提炼有意义的洞察。你可以上传文档，Claude 将帮助你理解复杂信息——这得益于 Claude 的大容量上下文窗口（Context Window），它可以接收 200K 以上的 token（约 500 页文本或更多），在使用 Opus 4.7 模型时，Pro、Max、Team 和 Enterprise 套餐最高支持 1M token。这让 Claude 能够在单次对话中处理大量材料。
- 编程辅助：Claude Opus 4.7 是我们目前最强大的模型，也是全球最优秀的编程模型。它在真实编程任务上的强劲表现意味着 Claude 可以帮助你编写、调试和解释多种编程语言的代码。
- 问题解决与推理：Claude 可以处理复杂的认知任务、数学问题、战略思考与分析以及研究工作。Claude Opus 4.7 和 Sonnet 4.7 是混合模式模型，提供两种模式：近乎即时的响应和用于更深层推理的深度思考（Extended Thinking）。Anthropic 深度思考模式允许 Claude 逐步解决问题，使其特别适合需要仔细分析的任务。
- 学习新事物：无论你是在学习新技能、探索陌生领域，还是在应对复杂挑战，Claude 都能适应你的学习风格和节奏。学习模式（Learning Mode）是一种新的 Claude 体验，它引导你的推理过程而非直接提供答案，帮助培养批判性思维能力。

### 访问 Claude 的方式

Claude 是智能核心——你通过本课程正在学习使用的 AI 助手。同样一个智能核心可以通过多种界面访问，每种界面适合不同类型的任务。

- Claude.ai（以及相关的移动端和桌面端应用）是大多数人使用 Claude 的主要方式。在这里，你可以提问、头脑风暴创意、创建和编辑文档等等。Claude.ai 非常适合对话、写作辅助、研究、分析以及创建文件。这也是本课程的重点。
- Claude Code 是一款智能代理编码工具，专为开发者设计，但也可用于桌面上的各种文件操作。Claude Code 可以直接编辑文件、运行命令和创建提交（Commit）。
- Claude 与 Slack 将 Claude 直接带入你团队的沟通工具中。你可以在任何频道或对话的 AI 助手栏中与 Claude 聊天，也可以在线程中 @Claude 提及它。当你将 Slack 连接到 Claude 后，Claude 会搜索你工作空间中的频道、私信和共享文件，以找到你需要的上下文，从而提供更好的回答和研究结果。
- Claude for Excel 让你可以在 Microsoft Excel 的侧边栏中直接使用 Claude，Claude 可以读取、分析、修改和创建新的 Excel 工作簿。Claude for Excel 最适合模型分析、假设更新、错误调试、模板填充、公式说明和多标签页导航。

本课程将主要聚焦于 Claude.ai，但你也可以参阅 Claude Code in Action 课程以获取在开发工作流中使用 Claude 的更多信息。
