# Claude 101

## 用构件进行创作 (Creating with Artifacts)

预计时长：20 分钟

### 学习目标

完成本课后，你将能够：

- 解释什么是构件（Artifacts）以及 Claude 在什么条件下会创建它们
- 与同事共享构件并公开发布
- 排查常见的构件问题

### 什么是构件？

构件是 Claude 在对话旁边的专属窗口中创建的独立、互动式输出产物。与埋在聊天记录中的大段代码或文本不同，你可以直接看到已渲染、可直接使用的内容——无论是一个可运行的网站、一张互动式图表，还是一份可以立刻下载的文档。

当内容满足以下条件时，Claude 会自动创建构件：

- 内容重要且自包含，通常超过 15 行
- 是你可能想要编辑、迭代或复用的内容
- 代表了无需依赖外围对话即可独立存在的复杂内容
- 是你将来会想参考或使用的内容

### 常见的构件类型

Claude 可以创建不同类型的构件，每种适用于不同需求：

- 文档（包括 Markdown、纯文本、Word 文档、PDF、PowerPoint 和 Excel）：非常适合一切文字量大的内容，你可能想导出或继续编辑——如会议记录、报告、项目计划、博客文章和其他书面内容。
- 代码片段：任何编程语言（Python、JavaScript、C++ 等）的可运行代码。你可以查看代码、复制或下载到自己的项目中使用。
- HTML 页面：包含 HTML、CSS 和 JavaScript 的单文件完整网页。非常适合落地页、表单、互动式演示或快速原型。
- SVG 图片：用于 Logo、图标、插画和其他视觉元素的可缩放矢量图形。这些图形可以直接在构件窗口中渲染，所见即所得。
- Mermaid 图表：流程图、时序图、甘特图、组织架构图等。描述你想可视化的关系，Claude 就会创建一张你可以继续优化的图表。
- React 组件：具有真实功能（如计算器、仪表盘、游戏、数据可视化）的交互式 UI 元素。这些不仅是静态模型；它们包含实际逻辑并能响应用户输入。

### 创建你的第一个构件

创建构件就像进行对话一样简单。只需描述你想要什么，Claude 会自行判断是否以构件形式呈现。

例如，你可以说：

- 「创建一张展示我们客户入职流程的流程图」（注：Claude 现在可能会使用 Imagine 功能将流程图以 HTML 形式进行可视化生成，除了基于代码的构件之外）
- 「构建一个互动式仪表盘，让我可以输入每月开销并查看分类汇总」
- 「为一个生产力应用设计一个包含主视觉区和功能列表的落地页」
- 「撰写一份我可以复用于新项目的项目简报模板」

如果 Claude 没有在你期望时自动创建构件，你可以明确要求：「请将此创建为构件」或「以构件的形式展示给我」。

当 Claude 生成构件时，它会出现在对话右侧的专属窗口中。在这里，你可以：

- 切换查看格式：在预览（呈现效果）和底层代码之间切换
- 复制内容：点击复制图标将内容复制到其他地方使用
- 下载文件：将构件保存为文件到你的电脑
- 查看代码：查看 Claude 在底层生成的具体内容

### 共享与发布构件

创建了有用的内容后，你有多种分享方式。

复制或下载：对于个人使用或通过其他渠道分享，使用构件窗口右下角的复制或下载按钮。

在组织内共享（Claude for Work）：Team 和 Enterprise 用户可以在组织内部与同事共享构件。共享的构件仅限于你的组织内访问，需要团队身份认证。

公开发布：对于 Free、Pro 和 Max 用户，你可以发布构件，让任何拥有链接的人都能访问。发布时请注意：

- 仅选定的版本会变为公开内容（你的聊天记录保持私密）
- 任何人都可以在没有 Claude 账号的情况下查看和与构件互动
- 其他人可以「重新创作」（Remix）你的构件——在他们自己的 Claude 对话中打开并进行修改和扩展

要发布构件，点击构件右上角的「分享」或「发布」按钮。你可以随时返回该构件并移除公开访问权限来取消发布。注意：发布构件后，通过其链接即可公开访问——任何人即使没有 Claude 账号也能查看。已发布的构件不会被搜索引擎索引，因此不会出现在 Google 搜索中。

### 充分利用构件的技巧

明确说出你想要什么。「构建一个预算追踪器」不错，但「构建一个月度预算追踪器，可以按分类输入支出、查看饼图汇总，并在超预算时收到警告」更好。

描述最终用户。告诉 Claude 谁会使用这个构件，有助于它做出合适的设计选择。「这是给新员工看的流程图」与「这是给工程团队看的流程图」会带来截然不同的结果。

逐步迭代。一次只让 Claude 添加一个功能或做一处修改。这样更容易识别哪些地方有效，并尽早发现问题。

需要时主动要求构件。如果你要求的是一段实质性内容，Claude 却在聊天中直接回应而非创建构件，直接说「请将其作为构件创建」。

### 课程反思

继续之前，请思考：

- 哪些重复性工作能受益于拥有一个可复用的互动式构件？
- 你工作中的哪些流程用流程图或图表呈现会更清晰？
- 什么原型或工具能帮助你快速测试一个想法？
