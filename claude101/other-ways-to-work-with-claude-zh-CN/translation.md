# Claude 101

## 与 Claude 协作的其他方式 (Other Ways to Work with Claude)

预计时长：10 分钟

### 学习目标

完成本课后，你将能够：

- 理解何时使用 Claude 的其他产品，包括 Claude Code、Claude for Slack、Claude for Excel、Claude for PowerPoint 和 Claude for Chrome

正如我们在课程开始时提到的，Claude 是一种智能。Claude.ai 只是与之协作的方式之一。

Claude 还提供了多款专为在你已有的工作环境中与你相遇而设计的专业工具。本课介绍另外五种与 Claude 协作的方式，每种针对特定的工作流和用例量身定制。

### Claude Code

[嵌入内容]

Claude Code 是一款智能代理（Agentic）编码工具，在你工作的任何地方都能使用——终端、IDE、浏览器，甚至是 Slack。它能理解你的代码库，执行命令，并通过自然语言处理整个开发工作流。

何时使用 Claude Code：

- 你想用简单英文描述需求来构建功能，让 Claude 编写代码、运行测试并创建提交（Commit）
- 你需要通过粘贴错误信息来调试问题，让 Claude 分析你的代码库来定位和修复问题
- 你在浏览一个不熟悉的代码库，想询问不同部分是如何协同工作的
- 你想自动化繁琐任务，如修复 Lint 错误、解决合并冲突或撰写发布说明
- 你更喜欢在终端中与你已有的 IDE 和开发工具一起工作，而不是切换到另一个独立界面

### Claude in Slack

[嵌入内容]

Claude 直接集成到 Slack 中，让你可以在频道和线程中获取帮助，或将 Slack 上下文带入你的 Claude 对话。

何时使用 Claude in Slack：

- 你想在不离开 Slack 的情况下草拟消息回复、总结长篇讨论或拆解复杂对话
- 你需要为会议做准备，让 Claude 从你的工作空间中整理相关对话和共享文档
- 你正在加入一个新团队，想通过查看频道历史来帮助理解正在进行的项目
- 你想直接从 Bug 报告或功能讨论中将编码任务交给 Claude——只需 @Claude 标记，它就能利用周边上下文启动一个 Claude Code 会话
- 你需要在对话中快速获取关于行业趋势、技术概念或公司信息的答案

### Claude for Excel

[嵌入内容]

Claude for Excel 通过侧边栏将 Claude 直接引入 Microsoft Excel，让你可以通过对话分析、理解和修改电子表格。

何时使用 Claude for Excel：

- 你正在处理一个包含多标签页的复杂工作簿，想了解特定公式或计算流程如何跨工作表运行
- 你需要在整个模型中更新假设条件或输入数据，同时保留公式依赖和关联关系
- 你正在调试诸如 `#REF!`、`#VALUE!` 或循环引用等电子表格错误，想让 Claude 追踪到错误源头并提出修复建议
- 你想创建新的电子表格或为现有模板填充数据，同时保持正确的公式结构
- 你需要快速构建数据透视表或图表来可视化数据

### Claude for PowerPoint

Claude for PowerPoint 通过侧边栏将 Claude 引入 Microsoft PowerPoint，让你可以通过对话起草、编辑和重组演示文稿，同时保持你现有的模板和品牌风格不变。

何时使用 Claude for PowerPoint：

- 你想将一份大纲、文档或一组笔记转化为第一版幻灯片，而不需要逐页手工制作
- 你需要改写或精简幻灯片文案——缩短要点、添加演讲者备注，或针对特定受众调整语气
- 你正在重组一份现有演示文稿，想获得关于重排章节、拆分过于密集的幻灯片或合并重叠内容的帮助
- 你希望在整份演示文稿中应用一致的格式——标题、要点样式和布局——而不需要逐页手动修改
- 你想获得针对某页幻灯片的视觉建议，例如哪种布局或图表类型最适合你要表达的观点

### Claude for Chrome

[嵌入内容]

Claude for Chrome 是一款浏览器扩展，将 Claude 以侧边栏形式添加到 Google Chrome 中。它可以观察你正在处理的内容，并直接在你的浏览器中执行操作。

何时使用 Claude for Chrome：

- 你想在浏览过程中总结文章、研究论文或网页内容
- 你需要帮助草拟邮件回复或管理收件箱
- 你正在填写重复性表单，想将流程自动化
- 你想测试网站功能或浏览多步骤工作流，而无需手动逐步点击
- 你需要一个在标签页和任务之间切换时保持上下文的浏览助手。这让它非常适合从冷门的内部工具、CRM 或仪表盘中提取上下文

重要提示：Claude for Chrome 目前处于研究预览（Research Preview）阶段。Anthropic 建议将其用于可信网站上的低风险任务。该扩展在执行购买或共享个人数据等高风险操作之前会征求你的许可，某些类别的网站（金融服务、成人内容）默认被屏蔽。

### 总结

这些工具分别将 Claude 的能力扩展到你的具体工作环境中：

| 工具 | 最适合 | 运行环境 |
| --- | --- | --- |
| Claude.ai | 通用任务、调研、写作、分析、文件创建 | 网页端、桌面端和移动端应用 |
| Claude Code | 软件开发、代码库浏览、git 工作流 | 终端/命令行、IDE 或浏览器 |
| Claude Cowork | 复杂、多步骤任务：研究简报、文档创建、文件整理、数据分析 | 桌面端（及通过 Dispatch 的移动端） |
| Claude/Claude Code in Slack | 团队协作、会议准备、上下文中的快速回答 | Slack 工作空间 |
| Claude for Excel | 电子表格分析、财务建模、公式调试 | Microsoft Excel 侧边栏 |
| Claude for PowerPoint | 幻灯片创建、演示文稿编辑、格式与设计 | Microsoft PowerPoint 侧边栏 |
| Claude for Chrome | 网页调研、邮件管理、浏览器自动化 | Chrome 浏览器侧边栏 |
