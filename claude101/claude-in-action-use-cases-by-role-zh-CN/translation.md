# Claude 101

## Claude 实战：按角色分类的用例 (Use Cases by Role)

预计时长：10 分钟

### 学习目标

完成本课后，你将能够：

- 描述 2-3 个你可以立刻尝试的 claude.ai 使用场景
- 知道在哪里找到更多用例灵感

无论你从事什么工作，Claude 都能帮助简化你的工作流程。本课按角色整理了实用的用例，让你看到 Claude 如何适用于你具体的工作场景。

以下每个用例都链接到我们用例展示库（Use Case Gallery）中的详细指南，其中包含你可以逐步操作的说明。

### 通用职业场景

这些用例适用于多种角色和行业。

- 生成项目状态报告——用清晰、一致的更新信息让利益相关者保持知情
- 分析用户反馈中的规律——从客户评论和问卷回复中提取洞察
- 将你的品牌指南打包为技能——创建一个可复用的 Claude 技能来应用你的品牌标准

### 销售

销售专业人士可以使用 Claude 来加速交易准备、创建有说服力的材料，并随时把握竞争情报。

- 构建竞争对比卡库——创建帮助你团队赢得交易的竞争情报资源
- 为销售谈判做准备——在重要会议之前研究潜在客户并组织你的谈话要点
- 创建销售报告——将你的销售管道数据转化为清晰、可执行的报告

### 市场营销

营销人员可以利用 Claude 分析效果数据，并在不同渠道之间高效复用内容。

- 分析营销活动效果——从营销指标中提取洞察，为你的策略提供参考
- 跨平台适配内容——针对不同渠道和受众高效复用内容

### 财务

财务专业人士可以使用 Claude 构建模型、起草文档，并理解复杂的电子表格。

- 构建财务模型——在 Claude 的帮助下创建和优化财务预测
- 起草投资备忘录——更高效地组织和撰写投资分析
- 理解并扩展已有电子表格——解码复杂电子表格并添加新功能

### 人力资源

人力资源团队可以使用 Claude 创建更好的入职体验和文档。

- 创建新员工入职指南——为不同角色量身开发全面的入职材料

### 法务

法务专业人士可以使用 Claude 来跟踪复杂的时间线和处理证据开示流程。

- 跟踪证据开示时间线并分析规律——整理案件时间线并在法律文件中识别关键规律

### 研究

研究人员可以使用 Claude 来规划文献综述和验证数据分析。

- 规划你的文献综述——系统性地组织你的学术文献检索方法
- 从原始数据中验证统计数据——复核计算和统计分析
