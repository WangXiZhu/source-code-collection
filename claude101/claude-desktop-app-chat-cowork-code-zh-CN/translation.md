# Claude 101

## Claude 桌面应用：Chat、Cowork、Code

学习内容

预计时长：6 分钟

完成本课后，你将能够：

- 识别 Claude 桌面应用的三种模式——Chat（对话）、Cowork（协作）和 Code（编码）——以及每种模式的设计用途

- 根据你需要完成的工作类型选择合适的模式

## 导航 Claude 桌面应用：Chat、Cowork、Code

Claude 桌面应用为你提供了三种使用 Claude 的方式：Chat、Cowork 和 Code——从快速提问到复杂研究再到构建软件。

Chat 是你在 claude.ai 上已熟悉的 Claude，外加来自在计算机原生运行所带来的快速唤起、截图、语音输入和连接器。Cowork 是一款智能代理（Agentic）工具——你给它一个目标，将它与你的工具和资源连接起来，然后让它去完成工作。借助 Cowork，Claude 拥有更广的触达范围和更大的工作空间。这种更宽阔的视野使它能够进行更全面的调研和分析，并产出更复杂的文档和交付物。Code 用于构建软件，从编写和测试代码到部署上线。

Cowork 和 Code 运行在同一个引擎上。两者底层都是 Claude Code——在本地机器上运行，能够独立工作，可以启动子智能体（Subagents）并持续执行长任务。这使得 Claude 能够独立处理更大的任务，如调研和写作，或构建软件。

每种模式都围绕其所服务的工作类型而设计，为你展示最重要的信息，并在你需要的地方给予控制权。

## Chat

当你需要提问、头脑风暴、起草文件或通过来回对话解决问题时，Chat 最为出色。

如果你使用过 claude.ai，这里的体验是一样的，外加一些来自在计算机原生运行所带来的功能：

- 快速唤起。在 Mac 上双击 Option 键即可在当前工作内容之上调出 Claude。它在一个紧凑的窗口中响应，并在你切换应用时保持在最上层。你无需离开正在做的事就能提问。
- 截图和窗口共享。截取屏幕截图或共享一个窗口，让 Claude 精准看到你正在看的内容。比描述屏幕上的内容更快、更精确。（Mac）
- 语音输入。通过口述来梳理问题，而非打字。适用于你在理顺思路、远离键盘，或者说话比打字更快的工作场景。（Mac）
- 桌面连接器。通过连接器连接本地工具和服务，让 Claude 可以与你机器上的其他工具协同工作。

以下场景值得一试：

- 你面对一个陌生的仪表盘。双击 Option，在窗口上拖拽光标截图，问「这些指标是什么意思？」Claude 在浮层中作答，仪表盘依然保留在视野中。
- 会议间隙你想梳理如何组织一篇演示文稿。打开快速唤起，切换到语音模式，把想法说出来。Claude 根据你所说的内容草拟大纲。
- 几周来你一直断断续续地在 Apple Notes 中记录产品发布的想法。从「设置」中添加 Notes 连接器，然后问 Claude：「把我笔记中所有关于 Osprey 发布的内容整理出来，找出哪些地方还没写完，再检查其他已连接的工具，看有没有能补全这些空白的信息。」Claude 在你本机读取笔记，拼凑你已有的信息，并在你思路中断处接续跟进。

## Cowork

Claude Cowork 专为需要真正投入精力的工作而打造：从众多来源中提取信息，加以理解和分析，并产出完整的最终成果。

在 Cowork 中，Claude 可以多任务并行处理，同时推进项目中的不同部分，因此它有足够的空间引用更多来源，并有足够的续航来将事情做到底。全面的研究简报、跨来源的财务分析、端到端的合同审阅、从分散来源的材料中整合出精美的幻灯片演示——这些都在 Cowork 的能力范围之内。

开始之前，Claude 通常会问一组简短的问题以明确你的需求：范围、格式、约束条件。它会构建一个你可以在侧边栏中查看的计划。在执行过程中，你会看到任务逐步成型：它正在使用的来源、正在生成的文件、计划的推进情况。你可以同时运行多个任务，每个任务在各自独立的对话中进行，从侧边栏切换不同任务。

- 文件夹访问。为 Claude 指定你计算机上的一个文件夹，它会读取其中的内容，判断哪些与当前任务相关，并将完成的工作保存回同一位置。你也可以上传文件、将内容粘贴到对话中，或连接能拉取所需信息的工具。
- 定时任务。Claude 可以按计划处理重复性工作：一份从你的 Slack 和日历中汇总的每日简报、一份每周发布内容汇总、一次每天早上的收件箱分类，帮你识别需要关注的事项。你定义任务内容和执行计划，Claude 会在应用打开时自动处理。如果你的电脑或应用在任务到期时处于关闭状态，它会在你回来后补上。
- 子智能体（Subagents）。Claude 启动的后台工作单元，用于并行处理任务的各个部分。如果你请求的是复杂任务——比如一份引用多个来源的研究简报——Claude 会将任务拆分为子任务，为每个子任务分配一个具有独立上下文的子智能体，然后协调各个结果，最终交付一份完整的成果。
- 调度（Dispatch）。一条持久存在的对话线程，让你可以从手机上继续你的 Cowork 对话。通过 Claude 移动应用，你可以将使用你计算机上一切资源的任务交给 Claude——你的文件、连接器、插件，甚至桌面应用。要使用此功能，你需要同时拥有桌面和移动端应用，计算机保持唤醒状态并且桌面应用处于打开状态。
- 项目（Projects）。Cowork 中的项目允许你将相关任务分组到各自拥有独立文件、上下文、指令和记忆的专用工作空间中。如果你在 Claude 上使用过项目，Cowork 中的项目与之类似，但它们存在于你的桌面本地，并围绕你通过 Cowork 运行的任务而构建。
- 浏览器操控（Browser Use）。在 Chrome 中连接 Claude，Claude 就能导航网页、与页面交互，并将找到的内容直接拉入正在执行的任务中。这就是 Cowork 可以完成如在十个网站之间对比竞品定价、或从没有 API 的页面搜集数据等任务的实现方式。
- 计算机操控（Computer Use）。当 Claude 没有现成的连接器或插件来处理你的需求时，它可以直接操控你的计算机——像你一样点击、打字和打开应用。Claude 遵循优先级顺序：连接器优先，其次是 Chrome，然后是屏幕交互，因此它总能选择最快、最可靠的路径。在 Claude 访问每个应用之前，你会看到权限提示，并且可以设置一个禁止列表来限制不希望被访问的内容。Computer use 在 Pro 和 Max 套餐中处于研究预览阶段，仅支持 macOS（Windows 即将推出）。
- 插件（Plugins）。插件赋予 Claude 它自身不具备的能力：获取实时金融数据、搜索公司内部知识库，或在特定的合规框架下工作。从 Cowork 界面浏览并添加插件以适配当前任务。
- 受保护环境。Cowork 在你计算机上的一片受限空间中运行。Claude 可以读取、创建和编辑你共享的文件夹中的文件，但无法访问文件夹之外的内容。

以下场景值得一试：

- 你想像查询数据库一样查询所有工具。问「回顾我们上个季度关于定价的决定，在会议记录、Slack 和邮件中分别是怎么讨论的，然后把发现整合到我们的 Q3 演示文档中」，Cowork 会在会议记录、幻灯片、邮件和 Slack 线程中找到答案。
- 你正在研究一个新市场、分析竞品、评估工具。对于任何可能跨越多个标签页且信息难以提取的研究工作，Cowork 会访问网站、阅读报告、获取定价，并提供一份带有来源的结构化简报，而你一个浏览器标签页都不需要打开。
- 你需要处理一个包含 50+ 份项目文档的文件夹，含合同、财务报告和会议转录文字。你可以请 Cowork 找出与你的计划最相关的文档并生成一份摘要备忘录。Cowork 会逐页阅读，在全集范围内交叉比对，提取出只有通读全部才能发现的规律。以审阅五份文档的速度审阅五十份。
- 你每天早上都在做同样的事情——查看消息、整理状态更新、为当天会议做准备。将其一次性设置为定时任务，Claude 会持续执行，这样你可以从答案开始新的一天，而不是从行政琐事开始。

Cowork 面向 Pro、Max、Team 和 Enterprise 用户开放，新功能正在持续增加中。

## Code

Code 标签页让你可以直接在桌面应用中使用 Claude Code 的强大能力。这为你提供了构建软件的完整开发环境。

通过 Code，Claude 直接在你的代码库中工作：读取现有代码、编写和修改代码、运行命令。可视化差异（Diff）显示变更内容，内置终端显示命令执行过程，git 追踪每个版本，让你随时可以回滚。

Cowork 在你共享的文件夹限定的受限工作区中运行，而 Code 直接在你的项目中运行，拥有对文件系统、终端和开发工具的完整访问权限。

你选择工作发生的位置：

- 本地（Local）：你在计算机上选择一个文件夹，Claude 直接处理这些文件。由于在本地运行，Claude 可以读取你的项目、访问本地工具，并启动一个开发服务器供你在浏览器中预览。
- 远程（Remote）：你连接一个 GitHub 仓库，Claude 在云环境中工作。即使你关闭应用，会话也会继续，因此你可以开始一次大规模重构，稍后再回来查看结果。适合较大的代码库，或当你想让开发工作不在本地机器上运行时。

三种交互模式让你控制 Claude 的自主程度：

- Ask（询问）：Claude 每次变更都会先提出建议并等待你的批准。在代码被修改之前，你查看可视化差异并决定接受还是拒绝。
- Code（编码）：Claude 自动应用文件变更，但在运行终端命令前会征得你的确认。
- Plan（规划）：Claude 在修改任何内容之前先规划完整的策略。一个专用的计划查看器让你在工作推进过程中查看和回顾策略。

你可以跨项目运行多个会话，并从侧边栏按状态（活跃或已归档）和环境（本地或云端）进行筛选。

Code 标签页面向 Pro、Max、Team 和 Enterprise 用户开放。

## 三种模式对比

|  | Chat | Cowork | Code |
| --- | --- | --- | --- |
| 优化场景 | 快速交流：探索想法、迭代起草、快速回答、通过对话学习 | 复杂或持续性工作：调研、分析、文件整理、生成完整的文档和交付物 | 构建软件：编写、测试、运行和部署代码 |
| 核心功能 | 快速唤起、语音输入 | 本地文件夹操作、插件、子智能体、定时任务 | Ask/Code/Plan 模式、可视化差异、git 集成、本地和远程环境 |
| 工具与扩展 | 连接器、技能、Claude in Chrome | 连接器（本地和远程）、技能、Claude in Chrome、插件、Computer Use | 连接器、技能、Claude in Chrome、插件、钩子（Hooks） |
