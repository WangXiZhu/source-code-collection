#### 核心要点

- Claude 是一个强大、智能的合作伙伴，能在你所有工作中增强你的能力。Claude 带来 AI 的智慧，而你提供让工作真正有价值的上下文和专业知识。
- 与 Claude 交流的最佳方式，就是像和同事说话一样——自然、简洁、对话式。
- 在下一场与 Claude 的对话开始前，请思考这几方面：设定舞台（你的角色、目标和上下文），明确任务（你希望 Claude 执行什么操作），以及指定规则（风格、语气和示例）。
- 当你在对话中上传相关文档或背景资料时，Claude 会在回答中综合考虑这些内容——可以把它看作让 Claude 快速理解你需求的捷径。
- Claude 真正的力量来自持续、频繁的交流，而不仅仅是一次性的提示。

### 开始你的第一次对话

当你打开 Claude.ai 时，你会看到一个简洁的界面，屏幕底部有一个文本输入区域。

你的提示词范围可以从简单的问题（比如为一个新功能头脑风暴代号）到复杂的请求，如共同创建文件。

### 编写有效的提示词

所有与 Claude 的交互都从一个提示词开始，这些提示词结合其他上下文，共同影响 Claude 的回答。与 Claude 交流的最佳方式就是像和同事说话一样——自然、简洁、对话式。

但你可能想问：什么样的提示词才算好提示词？在下一场与 Claude 的对话之前，请考虑以下几点：

1. 设定舞台：你的角色和目标是什么？Claude 需要了解你工作中的哪些背景信息？
2. 明确任务：你希望 Claude 执行什么操作？你是希望 Claude 写作、分析、构建，还是其他？
3. 指定规则：你希望 Claude 使用什么风格或语气？有没有可以附上的示例，用来向 Claude 展示你想要的效果？

### 添加上下文

文件上传、连接器（Connectors）和自定义偏好设置为向 Claude 提供更多工作上下文提供了多种方式。

Claude 可以分析 PDF 和其他文档中的文本与视觉元素（如图片、图表和图形）。支持的文件类型包括 PDF、DOCX、CSV、TXT，以及常见的图片格式如 PNG 和 JPEG。

一些文件上传的实用方式：

- 上传一份文档，请 Claude 总结要点
- 分享一张图片，请 Claude 描述或分析它所看到的内容
- 附上一份电子表格，请 Claude 识别数据中的趋势
- 上传代码，请 Claude 解释其工作原理或查找缺陷

文件上传后，Claude 会自动尝试解析文件内容。在聊天中，文件会显示为附件，你可以据此向 Claude 提问。

小技巧：如果你希望 Claude 在每次回复中都考虑特定偏好，前往「设置」>「通用」>「Claude 应考虑哪些个人偏好？」来设置对所有对话都适用的偏好。

### 在 Claude 的回答上持续迭代

与 Claude 的对话本身就是设计为可迭代的。将简短精炼的提示词串联起来，可以形成一种自然的对话方式，你基于 Claude 的回复来引导对话走向。

如果 Claude 的第一次回答不完全符合你的预期，你有以下几种选择：

提出追问：在 Claude 的回答基础上请它展开细节、换个角度或进一步说明。例如：「能把第二点展开说一下吗？」或「很有帮助，但可以更简洁些吗？」

提供反馈：告诉 Claude 你喜欢和不喜欢的地方。「内容不错，但语气太正式了，能改得更口语化一些吗？」

重新引导或重新开始：如果 Claude 跑偏了方向，直接把它拉回来。「其实我问的是 X，不是 Y。让我重新说一下……」最坏的情况是在新对话中重新开始，以完全刷新上下文。

小技巧：你也可以点击任意一条你发送的消息上的铅笔图标来编辑并重新提交提示词——当你想要优化你的需求而非添加新消息时，这非常有用。

### 个性化你的 Claude

有两个功能可以帮助 Claude 随时间推移更贴合你的工作方式，增强提示词的效果。

记忆（Memory）会自动保存你对话中的关键上下文——你的角色、偏好、过往决策和工作风格——这样你就不必在每次开新对话时重复一遍。例如，如果你告诉 Claude 你在一家 B2B 公司从事市场营销工作，它之后就会记住这个背景。你随时可以在「设置」中查看、编辑或删除 Claude 记住的任何内容，并且记忆会在你所有设备之间同步。

风格（Styles）让你可以自定义 Claude 的沟通方式。从预设选项中挑选——如简洁、正式或解释性——或者通过描述你希望 Claude 如何写作来创建你自己的自定义风格。设置好之后，你的风格将自动应用于所有对话。
